# 52户型装修设计（Windows 桌面版）

> 一张图纸进去，一个能改的方案出来：自动识墙、自动分房间、一键布水电、2D/3D 换着看、报价与施工图直接导出。
> 纯本地运行，不联网、不上传，所有数据都在你安装它的那个目录里。

![version](https://img.shields.io/badge/version-1.4.2-2563eb) ![platform](https://img.shields.io/badge/platform-Windows%20x64-0f172a) ![license](https://img.shields.io/badge/license-MIT-16a34a)

## 简介

做导航站（52jsdh.cn）的人自己装修时踩出来的软件。市面上的户型工具大多要么只能画平面、要么绑账号上网、要么导出还要付费；
这个项目把「识别图纸 → 户型建模 → 水电点位 → 报价 → 施工图」整条线做进了一个离线 Windows 程序：

- **导入 CAD 图纸（DXF）自动识墙**：图层盘点与勾选，双线墙皮配对成「墙中线 + 墙厚」，端点吸附成墙角，自动分房间、自动布水电。
- **导入户型图片自动识墙**（v1.3.0 新增）：PNG / JPG / BMP / WEBP 直接读，认出实心墙与双线墙，填一次比例尺就出方案。
- **尺寸标注校核 + 整栋一次成型**（v1.3.0 新增）：读图上的标注数字和识别结果逐条对账；一张图里画了几层就生成几层。
- **导入户型图当底图描图**（照片、售楼处户型图、酷家乐截图都行）：拉一段已知尺寸校准比例，照着底图描墙。
- **2D / 3D 一体**：平面编辑、整栋鸟瞰、第一人称漫游、720° 全景、按层隔离与平铺。
- **水电到回路**：开关插座灯具弱电水点、强弱电分回路、管线自动排布与手画纠错、3D 里点开关。
- **出图与报价**：PDF 施工图（标注、门窗尺寸、房间面积）、三种 DXF、彩平图、报价表、方案 JSON 与分享文件。
- **方案对账**（v1.3.0 新增）：结构问题、尺寸链偏差、墙体往返一致性，一条命令出一份报告。
- **画墙画管线不跑偏**（v1.4.1 新增）：画墙 / 画管线时光标旁直接写方向和偏移角度（`水平 · 偏 1.2°，已吸附`），画歪了还能在属性面板里改角度，长度不变。
- **交付包**（v1.4.0 新增）：一键出「顶视看板图（日 / 夜）+ 设备档案与实体映射表 + 配电箱回路表」，坐标 JSON 与 Home Assistant `picture-elements` 卡片片段一起给，画完能直接交给电工、也能直接上墙看板。

安装包开箱即用（NSIS，可自选安装目录），装完打开就是一张空白户型，自己导入自己的图纸。

## 和上游 house-plan-designer 的关系

设计器本体（`app/designer.html`）来自上游开源项目 [ZWD11/house-plan-designer](https://github.com/ZWD11/house-plan-designer) 的设计器模板；
桌面外壳、DXF 识别、图片识别、对账脚本、外观层与安装打包由本项目维护。两者定位不同：

| 环节 | 上游（Agent Skill） | 本软件（桌面版） |
|---|---|---|
| 怎么开始 | 把图纸交给 Agent，Agent 跑脚本识图、写方案 | 用户自己点菜单导入 DXF / 图片 / 底图 / 打开备份 |
| DXF（直线 / 多段线画墙） | 支持（含整套布置图、块套块、GBK 乱码） | 支持（LINE / LWPOLYLINE / POLYLINE） |
| 图片、黑底 CAD 截图 | 支持（OpenCV 提取墙体 + 尺寸数字 OCR + 轴网定比例） | ✅ 支持识墙（距离变换 + 游程 + 平行配对）；比例尺靠用户填实际总宽，暂不做标注 OCR |
| 扫描 PDF | 支持 | ❌ 请先转成图片或 DXF |
| 矢量 PDF 图纸 | 支持（直接读图元坐标） | ❌ 请先在 CAD 里导出 DXF |
| 块（INSERT）、填充、门弧、柱 | 展开块、按图层认门窗与柱 | 块需先在 CAD 里 `EXPLODE` 打散；不读填充与门弧 |
| 尺寸标注 | 以标注为准，逐刻度拟合，并列出图纸自相矛盾 | ✅ 读 `DIMENSION` 与 `TEXT/MTEXT` 数字逐条对账，偏差清单落地（口径：标注只校核，不硬改墙） |
| 双图对齐（原图 + 布置图） | 支持 | 不支持 |
| 整栋楼 / 复式 / 别墅 / 办公楼层 | 支持一次成型（含楼梯、电梯、场地） | ✅ 一张图里画了几层就生成几层（按墙群空带切分）；楼梯、电梯、场地在设计器里加 |
| 交付对账（墙体 / 尺寸链 / 家具 / 全功能验收） | 有（`wallaudit.py` / `check.mjs` / `qa.mjs` / `elecaudit.mjs`） | ✅ 结构 + 尺寸链 + 墙体往返三类，菜单与 `tools/audit.mjs` 两边都能跑（家具摆放与全功能验收还没有） |
| 交付物（看板图 / 设备档案 / 配电箱表） | 出施工图 PDF / DXF / 报价 | ✅ v1.4.0 新增：顶视正交看板图（日 / 夜、SVG + PNG）、设备档案与建议 `entity_id`、回路负荷与断路器表、HA `picture-elements` 坐标与卡片片段 |
| 设计器本体能力 | 完整 | 同一套模板，功能一致（含吊顶、自由造型、中控、光线追踪等） |

结论：**绘图、建模、水电、出图能力两边一致；读图入口的四个缺口在 v1.3.0 里补上了三个半**——
图片识墙、标注校核、整栋成型、对账都有了，还差「矢量 PDF / 块自动展开 / 标注 OCR 定比例 / 双图对齐」。

## 能读哪些图

| 输入 | 本软件支持 |
|---|---|
| AutoCAD 2013 DXF（直线 / 多段线画墙） | ✅ 推荐。图层盘点后勾选识墙，双线配对成墙，单线自动兜底 |
| DXF 里墙是块（INSERT） | ⚠ 先在 CAD 里 `EXPLODE` 打散再导出 |
| 老式 POLYLINE / 多段线 | ✅ |
| 彩色户型图、售楼处传单、酷家乐截图、扫描图、手绘平面图 | ✅ 自动识墙（`Ctrl+Alt+G`），需填一次「这套房的实际总宽」 |
| 矢量 PDF | ❌ 请先导出 DXF |
| DWG | ❌ 请先另存为 DXF |

**DXF 图层规则**（`app/dxf.js`）：

- 先盘点每个图层的线条数与总长，自动跳标注 / 尺寸 / 文字 / 轴线 / 图框 / 家具 / 门窗 / 填充等图层。
- 名字像墙的图层（`墙 / 墙体 / 隔墙 / WALL / A-WALL`）优先勾选；墙名图层线量不到最大图层 25% 时，把线量最大的 1~2 个图层也勾上；完全没有墙名图层时取线量前 3（可在浮层里自己改）。
- 双线成墙判据：平行（夹角 ≤ 1.6°）、侧别一致、间距 50~460 mm、两端点差小、重合 ≥ 较短线的 60%、两线长差不太大；之后单线兜底（≥ 900 mm 按 120 / 200 厚度）、去重、同角度合段（接口间隙 ≤ 80 mm）、短墙过滤（< 250 mm）、60 mm 端点聚类吸附、去除离主体的飞线。
- 输出一律是「墙中线 + 墙厚 + 承重判定（厚度 ≥ 180）」，交给设计器生成方案；层高固定 3000、楼板 120，可在设计器里改。

**图片识墙规则**（`app/imgwall.js`，纯 JS、零依赖）：

- 解码用 Electron 原生 `nativeImage`（不引 OpenCV、不联网），长边超过 2600 像素先等比缩小。
- 灰度后 Otsu 定阈值，反相判断（深底白线 / 浅底深线都吃）；墨迹占比 < 1.2% 直接判定「这张图没线条」。
- 两条互补取墙路径：**实心墙**先做距离变换，只留「够粗」的笔画（1~2 px 的家具框、尺寸线、门弧、点划轴线自然被滤掉），再按行 / 列游程切横墙竖墙；**双线墙**走细线游程 + 平行配对（间距与长度相近、重叠 ≥ 70%），中点即墙中线。
- 墙厚回到原始墨迹量（在墙 30% / 50% / 70% 三处取中位），全图统一用中位厚度，避免交叉口被量成两倍粗。
- 比例尺：识别完弹浮层，填「这套房的实际总宽（毫米）」或点 8 / 10 / 12 / 14 / 16 米常用值，按像素换算成毫米后生成方案。

**多层切分规则**（`splitFloors`）：把墙投影到 X / Y 轴，同一层内部投影连绵、层与层之间出现空带；空带宽度 ≥ max(2200 mm, 6% 跨度) 且两侧各 ≥ 4 道墙就切一刀，最多递归 5 层。单张平面不会被误切（自测里单张 → 1 层、并排两份 → 2 层）。

**尺寸对账规则**（`verifyDims`）：`DIMENSION` 用 13/14 两点距 + 旋转角；`TEXT/MTEXT` 取数字（自动剔除面积 ㎡、角度 °、比例 1:100、标高 ±0.000）。按方向匹配同向墙，长度先过 ±45% 粗筛再按「中心距 + 长度差」打分，容差 max(40 mm, 1.2%)；结果分「一致 / 偏差 / 严重 / 未匹配」，列表落 `data\对账\last-dims-report.json`。

## 生成的设计器能做什么

设计器本体是单文件前端（`app/designer.html`，2.5 MB），功能与上游一致：

**户型与结构**

- 画墙、拆墙、改门窗，面积实时重算；墙体转角 / 丁字口按相交墙厚度接合；薄墙接厚墙时墙面自动齐平。
- 画墙时贴着光标给方向判断：`水平` / `垂直` / `斜 45.0°（离横竖 45.0°）`，鼠标偏得只有一点点才吸平（当前横竖 5°、45° 系 3°，v1.4.2 收紧），吸了就写 `偏 1.2°，已吸附`，偏得明显就保持斜的。
- 外围三道尺寸、每段墙净长、房间开间 × 进深；左边可挂原图底图对照。
- 门窗 12 种：单开 / 双开 / 子母 / 推拉 / 折叠 / 隐形推拉 / 门洞；平开、推拉、落地（带护栏）、高窗、飘窗。
- 半圆墙、拆地板、补地板、墙高与洞口尺寸、多层加层复制。

**家具与定制**

- 家具库按空间分类（20 类 / 320 多件），搜索、9 种风格、一键整套换风格、大图浏览、点款式就地替换。
- 拖边只改宽或深、拖角等比、尺寸牌上直接输宽高深、「宽度 / 进深撑满两墙」。
- 掯捉变形：拖四个角点变梯形 / 斜切 / 平行四边形，一键「贴合斜墙」。
- 定制家具参数化：一字 / L / U 形橱柜（水槽灶台位置与宽度、台面高度、吊柜、电器高柜）、定制柜（每列宽与类型、L 转角、顶柜、踢脚拉手）、浴室柜与淋浴房、中岛；2D / 3D / 立面 / 报价 / 水电点位全同步。
- 自由造型工作台：草图画在地面或任意面上，推拉 / 挖洞 / 旋转成型 / 放样 / 抽壳 / 布尔，多选整组操作，模板起手，作品存进「我的造型」。

**3D 与效果**

- 2D 平面、3D 鸟瞰、第一人称漫游、720° 全景；锁防误触；左右面板收起 / 展开（`[` / `]`）与拖宽。
- 写实建模（程序生成，不依赖外部模型）+ 漫游光影（接触阴影、窗户面光源、反弹光、窗外远景）；画质三档。
- 光线追踪出图（带进度与剩余时间，可提前结束保存）。
- 真实日照（纬度 / 月份 / 时间）、晚霞与星月；彩平图、沙盘效果图、12 套主题配色。
- 智能中控（模拟演示）：多层切换与爆炸视图，灯光 / 环境 / 设备 / 扫地机 / 安防 五类图标浮在 3D 上。

**装修设计**

- 布置 / 水电 / 顶面 / 铺装 / 拆改 五个图层。
- 吊顶 7 种做法（平顶 / 边吊 / 回字叠级 / 悬浮 / 铝扣板 / 木饰面）+ 灯槽自动灯带 + 窗帘盒 + 石膏线 + 局部吊顶造型；灯带 / 磁吸轨道灯 / 线性灯沿线画。
- 自定义铺砖（尺寸、灰缝、铺法、起铺点、角度）；排灯（灯型、横纵间距、离墙距离，一键重排并改挂开关）。
- 独栋别墅：车库电动卷帘门、庭院围墙与车道口、车棚、泳池、凉亭、挑空客厅、电梯、设备间。
- 水电点位 33 种，一键布置水电（按功能区布灯、多门口与床头双控、插座沿墙补齐、弱电箱与排水）；方案检查（家具重叠、挡门、通道宽度、马桶坑距、吊柜挡窗、楼梯净高）。

**水电管线与出图**

- 五类管线自动排布（100 mm 网格 A* 寻路）：插座 / 照明回路、网线、冷热水、排水；回路表 + 材料清单；6 个视图分看；回路表点一行只看这一路。
- 管线手画、拖顶点、自动寻路、纠错一键修复；3D「管线」按真实高度透视。
- 画管线默认锁横平竖直（提示里写 `水平` / `垂直` + `偏 1.6°，已吸附`，按 Alt 才走任意角度）；选中一面墙或一条手画管线，右侧属性里能直接改「角度」/「末段角度」，长度不变（v1.4.1）。
- 导出：整套 A3 施工图 PDF、三种 DXF（平面布置图国标三道尺寸 / 装修四道尺寸 / 水电点位图）、彩平图 PNG、管线分类 DXF / PNG / PDF、回路与材料 CSV。
- 自动算量报价；多方案管理与对比；自动保存；「分享文件」打包整套方案。

**桌面版另外加的**

- 原生菜单（文件 / 编辑 / 视图 / 工具 / 帮助）与快捷键；另存为落盘到安装目录；最近打开；窗口位置记忆；单实例。
- 深色模式（连 Windows 标题栏与菜单栏一起变）、卡片化界面、左右侧栏点一下收起。
- 数据全部落在安装目录；首次打开空白；内置 DXF 识别、图片识墙、整栋成型与方案对账。

## 安装

1. 下载 `52户型装修设计-安装版-1.4.2.exe`。
2. 双击安装，**安装目录可以自己选**（默认在 `%LOCALAPPDATA%\Programs\52户型装修设计`，也可以换成 D 盘之类）。
3. 装完桌面 / 开始菜单会有「52户型装修设计」，打开就是一张**空白户型**。

> 没有自带任何示例方案。第一次打开是空的，你自己从 CAD 图纸 / 户型图片新建，或导入之前备份的 `.json`。

## 使用方法

### 方式一：从 CAD 图纸生成方案（精度最高）

1. 菜单 **文件 → 从 CAD 图纸新建（DXF）…**（`Ctrl+Shift+D`）。
2. 选一张 `.dxf`（AutoCAD 2013 DXF 及以上）。如果是 `.dwg`，先在 CAD 里「另存为 → AutoCAD 2013 DXF」。
3. 软件先列图层（每层多少条线、总长多少），自动勾上像墙的图层；墙画在 `0` 层的自己勾一下。
4. 确认框里核对：识别到几面墙、承重墙几面、图纸范围多少米、**图上标注几条 / 一致几条 / 偏差几条**。
5. 点「生成方案」→ 自动换成新方案并布水电；房间名在左栏改完再点一次「一键布置水电」会更全。
6. 若这张图里并排画了好几层，会先问一句「整栋生成 N 层 / 合成为一层」。

### 方式二：从户型图片生成方案（v1.3.0 新增）

1. 菜单 **文件 → 从户型图片新建（自动识墙）…**（`Ctrl+Alt+G`）。
2. 选一张 PNG / JPG / BMP / WEBP（售楼处户型图、酷家乐截图、扫描件、手绘照片都行）。
3. 软件自动识墙，弹一个浮层问「这套房的实际总宽」——量一下图上最外沿的总宽（毫米），或直接点 8 / 10 / 12 / 14 / 16 米。
4. 确认框核对识别到的墙数、墙厚、尺度，点「生成方案」→ 自动布水电。
5. 门洞、飘窗、家具图上的东西不识别，生成后在「门窗」工具里补。

### 方式三：导入户型图当底图描图

1. 左栏「户型」页 → **导入户型图**（或菜单 **文件 → 导入户型图（描图底图）…**，`Ctrl+Alt+I`）。
2. 拉一段图上标了尺寸的线，输入实际毫米数完成比例校准。
3. 用「画墙」照着底图描；画墙时直接输数字回车可以定长，按 `Shift` 取消角度吸附。

### 方式四：继续改以前的作品

菜单 **文件 → 打开方案…**（`Ctrl+O`）选之前导出的 `.json`，接着改。

### 交付包：看板图 + 设备档案 + 配电箱表（v1.4.0 新增）

菜单 **工具 → 导交付包（看板图 / 设备清单 / 配电箱表）…**（`Ctrl+Alt+D`）。跑完自动打开 `<安装目录>\data\交付\交付-<日期-时间>\`，里面是：

| 文件 | 用途 |
|---|---|
| `*-交付图.svg / .png` | 带点位编号 + 图例 + 比例尺 + 北针 + 本层统计的顶视图，打印或发给电工；图上编号与设备清单「序号」一一对应 |
| `*-看板底图-日 / -夜.svg / .png` | 干净底图（只有墙、房间名、面积），给 Home Assistant / 自家面板当背景 |
| `看板坐标-*.json` | 每个点位的百分比坐标（`leftPct` / `topPct`）、建议 `entity_id`、房间面积、视口 mm 范围 |
| `picture-elements-*.yaml` | 可直接贴进 HA 的 `picture-elements` 卡片 YAML |
| `设备清单.csv / .md` | 设备档案与实体映射表（楼层 / 房间 / 品类 / 建议实体域 / 建议 `entity_id` / 协议 / 回路 / 功率 / 高度） |
| `配电箱回路表.csv / .md` | 逐路负荷 W、计算电流 A、建议断路器、导线截面、要不要 30mA 漏保、超载标记，以及装接总功率与总闸建议 |
| `设备档案.json` | 母表；改完放回 `<安装目录>\data\设备档案\设备档案.json`，下次导出沿用你的改动 |
| `交付说明.md` | 口径、边界与怎么用 |

分路规则（估算）：照明整层一路（点数超 20 拆两路）；插座按房间聚、累计 ≤ 8 点一路；空调插座 / 16A / 充电桩 / 地暖温控 / 窗帘电机 / 换气扇各走专用回路。
所有功率按品类默认值估、线径与断路器按家用常见档位给，**都不当施工依据**——须持证电工按现场负荷、线长与规范复核。

### 方案对账（v1.3.0 新增）

菜单 **工具 → 方案对账（结构 / 尺寸链 / 墙体往返）…**（`Ctrl+Alt+A`）：

- 结构：每层墙数 / 墙总长 / 外框 / 短墙 / 疑似重复墙 / 悬空端点 / 楼层雷同。
- 尺寸链：若数据目录里记着最近导入的 DXF，就把它的标注再对一遍。
- 墙体往返：拿 DXF 重解析一遍，和当前方案的墙数、外包尺寸比。
- 报告（markdown + json）写到 `<安装目录>\对账\对账-<时间>.md` 并自动打开，结论分「通过 / 可用有提示 / 需修改」。

## 已知欠缺

诚实列一下现在的短板（欢迎 issue 或 PR）：

1. **矢量 PDF 不支持**，块（INSERT）要手工 `EXPLODE`，填充与门弧不读。
2. **图片识墙不做标注 OCR**：比例尺要你填一次实际总宽，不像上游那样从图上尺寸数字 + 轴网自动定比例。
3. **图片识墙对彩色渐变底、低对比截图不完美**：门洞、飘窗、家具、文字都不还原；斜墙会被按正交近似。
4. **整栋只切层、不建结构**：楼梯、挑空、电梯、庭院场地要在设计器里自己加。
5. **双图对齐（原图 + 布置图）没有**。
6. **对账只做几何**：不含结构安全、水电承重、消防等专业结论；家具摆放检查与上游 `qa.mjs` 级别的全功能验收还没有。
7. **导入后不自动摆家具**：自动分房间 + 一键水电已有，家具、定制柜、房间命名得自己来。
8. **交付包的数字是估算**：功率按品类默认值、线径与断路器按常见档位，不含结构 / 水电安全结论；`entity_id` 是建议命名，接不接得上取决于你接入的集成。

## 常见问题

**Q：能直接打开 DWG 吗？**
A：不能。DWG 是封装格式，需要完整 CAD 内核。请在 CAD 里另存为 DXF 再导入。

**Q：图片能自动识墙吗？**
A：能（v1.3.0）。菜单「从户型图片新建」`Ctrl+Alt+G`，认实心墙与双线墙；要填一次实际总宽当比例尺。识别结果只有直墙，门洞和家具要自己补。

**Q：导入后没有门窗？**
A：DXF 与图片都只还原墙体。门窗洞口、家具、文字标注不还原，导入后在「门窗」工具里补。

**Q：房间名都是「房间1、房间2」？**
A：房间是按墙围合自动分的，名字可以在左栏「房间」里改；改完再点一次「一键布置水电」，点位会按房间功能布得更全。

**Q：识别出来的墙不对 / 少了？**
A：DXF：先在图层浮层里换一组图层再试（CAD 里墙经常画在 `0` 或自定义图层上）；墙是块就先 `EXPLODE`。图片：换一张更清晰的图，或先裁掉家具多的区域；识完可以只留外墙再手画内墙。

**Q：标注和墙长对不上，听谁的？**
A：软件把差值列出来，不自动改墙。图上改过没倒标注很常见，多数情况以图线为准；确实是图错了，按标注手动改。

**Q：重装 / 升级会丢方案吗？**
A：不会。方案在安装目录的 `data\`（或回退目录），覆盖安装不删；卸载默认也保留。

**Q：导出的看板图能直接用在智能家居吗？**
A：能当底图用（v1.4.0）。`工具 → 导交付包`（`Ctrl+Alt+D`）出 `*-看板底图-日/夜.png` 与 `看板坐标-*.json`、`picture-elements-*.yaml`；把 PNG 放进 HA 的 `config/www/floorplan/`，YAML 贴进卡片即可。`entity_id` 是建议命名，能不能真控制取决于你接入的集成本身（米家 / 涂鸦 / Matter 等），本软件不接管设备。

**Q：配电箱表能直接照着施工吗？**
A：不能。表里的功率是按品类默认值估的，线径与断路器按家用常见档位给建议，只作方案阶段参考。实际分路、线径、断路器与漏保选型须由持证电工按现场负荷、线长与环境温度复核。
